## 🌿 Modelo de Versionamiento y Ramas
El versionamiento sigue las directrices oficiales del curso de Gitflow:
* `main`: Rama de producción. Contiene el código estable, verificado y probado físicamente en el hardware.
* `dev`: Rama de desarrollo e integración activa.
* `feature/<nombre-funcionalidad>`: Ramas de características independientes para cada laboratorio o módulo.

Toda integración a la rama `main` se realiza exclusivamente mediante **Pull Requests (PR)** aprobados y documentados.
